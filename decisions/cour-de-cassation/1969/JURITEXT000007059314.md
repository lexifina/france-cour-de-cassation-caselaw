# Cour de Cassation, Chambre criminelle, du 4 janvier 1969, 67-90.525, Publié au bulletin

## Sommaire

CODE DE LA ROUTE - Piste cyclable - Priorité - Automobiliste suivant la voie principale coupant la piste cyclable pour prendre une voie adjacente (non)

* CODE DE LA ROUTE - Piste cyclable - Définition - Voie ouverte à la circulation - Portée.

* CODE DE LA ROUTE - Piste cyclable - Automobiliste suivant la voie principale et coupant la piste cyclable pour prendre une voie adjacente.

* CODE DE LA ROUTE - Priorité - Piste cyclable - Application.

Les pistes cyclables visées à l'article R 190 du Code de la route font corps avec les chaussées en bordure desquelles elles se trouvent et de la nature desquelles elle participent. Elles constituent avec elle une voie unique. Il n'y a donc pas lieu à application de l'article R 25 du Code de la route sur le bénéfice de priorité lorsqu'un conducteur suivant la voie principale traverse la piste cyclable pour prendre une voie adjacente (1).
