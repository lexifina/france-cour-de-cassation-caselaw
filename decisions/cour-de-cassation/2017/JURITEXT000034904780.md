# Cour de cassation, civile, Chambre civile 2, 8 juin 2017, 17-60.182, Inédit

## Texte

LA COUR DE CASSATION, DEUXIÈME CHAMBRE CIVILE, a rendu l'arrêt suivant :

Vu les articles 1014 et 1015 du code de procédure civile ;

Vu l'article R. 15-2, alinéa 2, du code électoral ;

Attendu que, par application de ce texte, le pourvoi n'est pas recevable ;

Qu'il n'y a donc pas lieu de statuer par une décision spécialement motivée ;

DÉCLARE IRRECEVABLE le pourvoi ;

Ainsi décidé par la Cour de cassation, deuxième chambre civile, et prononcé par le président en son audience publique du huit juin deux mille dix-sept.
