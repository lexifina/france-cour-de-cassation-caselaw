# Cour de Cassation, Chambre civile 3, du 23 mars 1983, Inédit

## Texte

SUR LA RECEVABILITE DU POURVOI : ATTENDU QUE LA DECLARATION DE POURVOI SE BORNE A ENONCER QUE CELUI-CI EST FORME POUR EXCES DE POUVOIRS, INCOMPETENCE, VICES DE FORME ;

QUE CETTE ENONCIATION IMPRECISE ET VAGUE N'EQUIVAUT PAS A L'ENONCE MEME SOMMAIRE D'UN MOYEN DE CASSATION ;

QU'AUCUNE MEMOIRE AMPLIATIF N'A ETE PRODUIT DANS LE DELAI PRESCRIT, A PEINE D'IRRECEVABILITE, PAR L'ARTICLE R12-5 DU CODE DE L'EXPROPRIATION ;

PAR CES MOTIFS : DECLARE LE POURVOI IRRECEVABLE ;
