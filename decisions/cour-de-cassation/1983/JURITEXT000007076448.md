# Cour de Cassation, Chambre civile 3, du 23 mars 1983, Inédit

## Texte

SUR LA RECEVABILITE DU POURVOI : ATTENDU QUE LA DECLARATION DE POURVOI ET LE MEMOIRE AMPLIATIF SE BORNENT A ENONCER QUE CELUI-CI EST FORME PAR VIOLATION DES ARTICLES 545, 690 ET 1383 DU CODE CIVIL ;

QUE CETTE ENONCIATION IMPRECISE ET VAGUE N'EQUIVAUT PAS A L'ENONCE MEME SOMMAIRE D'UN MOYEN DE CASSATION ;

QU'AUCUN MEMOIRE AMPLIATIF PLUS PRECIS N'A ETE PRODUIT DANS LE DELAI PRESCRIT, A PEINE D'IRRECEVABILITE, PAR L'ARTICLE 989 DU NOUVEAU CODE DE PROCEDURE CIVILE ;

PAR CES MOTIFS : DECLARE LE POURVOI IRRECEVABLE ;
