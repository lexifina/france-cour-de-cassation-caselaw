# Cour de Cassation, Chambre civile 3, du 2 février 1983, Inédit

## Texte

SUR LA RECEVABILITE DU POURVOI : ATTENDU QUE LA DECLARATION DE POURVOI SE BORNE A ENONCER QUE CELUI-CI EST FORME POUR "INCOMPETENCE, EXCES DE POUVOIR ET VICE DE FORME" ;

QUE CETTE ENONCIATION N'EQUIVAUT PAS A L'ENONCE D'UN MOYEN DE CASSATION PRECIS, ATTENDU QU'AUCUN MEMOIRE AMPLATIF N'A ETE PRODUIT DANS LE DELAI PRESCRIT, A PEINE D'IRRECEVABILITE, PAR L'ARTICLE R 12-5 DU CODE DE L'EXPROPRIATION ;

PAR CES MOTIFS : DECLARE IRRECEVABLE LE POURVOI ;
