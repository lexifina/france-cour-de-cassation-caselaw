# Cour de Cassation, Chambre civile 3, du 23 mars 1983, Inédit

## Texte

SUR LA RECEVABILITE DU POURVOI : ATTENDU QUE LA DECLARATION DE POURVOI NE FORMULE AUCUN MOYEN REGULIER DE CASSATION, QU'AUCUN MEMOIRE AMPLIATIF N'A ETE PRODUIT DANS LE DELAI PRESCRIT, A PEINE D'IRRECEVABILITE, PAR L'ARTICLE R12-5 DU CODE DE L'EXPROPRIATION ;

PAR CES MOTIFS : DECLARE IRRECEVABLE LE POURVOI ;
