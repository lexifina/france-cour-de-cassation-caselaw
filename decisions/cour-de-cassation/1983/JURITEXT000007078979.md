# Cour de Cassation, Chambre sociale, du 24 février 1983, Inédit

## Texte

SUR LA RECEVABILITE DU POURVOI : VU L'ARTICLE 989 DU CODE DE PROCEDURE CIVILE, ATTENDU QUE LA DECLARATION DE POURVOI NE FORMULE AUCUN MOYEN REGULIER DE CASSATION ET NE VISE AUCUN TEXTE QUI AURAIT ETE VIOLE OU FAUSSEMENT APPLIQUE ;

QUE CETTE OMISSION N'A PAS ETE REPAREE PAR LA PRODUCTION D'UN MEMOIRE AMPLIATIF CONTENANT L'ENONCE, MEME SOMMAIRE, D'UN TEL MOYEN, DANS LE DELAI DE TROIS MOIS PREVU PAR LE TEXTE SUSVISE ;

PAR CES MOTIFS : DECLARE LE POURVOI IRRECEVABLE ;
