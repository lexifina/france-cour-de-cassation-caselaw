# Cour de cassation, civile, Chambre civile 2, 28 mai 2009, 09-60.084, Inédit

## Texte

LA COUR DE CASSATION, DEUXIÈME CHAMBRE CIVILE, a rendu l'arrêt suivant :

Vu l'article 1014 du code de procédure civile ;

Vu l'article R. 15-1 du code électoral ;

Attendu que, par application de ces textes, le pourvoi n'est pas recevable ;

DECLARE non admis le pourvoi ;

Ainsi décidé par la Cour de cassation, deuxième chambre civile, et prononcé par le président en son audience publique du vingt-huit mai deux mille neuf.
