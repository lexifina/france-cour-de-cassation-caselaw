# Cour de Cassation, Chambre sociale, du 29 avril 1986, 85-41.640, Publié au bulletin

## Sommaire

CASSATION - Affaires dispensées du ministère d'un avocat - Pourvoi - Déclaration - Mandataire - Pouvoir spécial - Pouvoir transmis par télex

PRUD'HOMMES - Cassation - Pourvoi - Déclaration - Mandataire - Pouvoir spécial - Pouvoir transmis par télex

PRUD'HOMMES - Cassation - Pourvoi - Déclaration - Mandataire - Pouvoir spécial - Production

Dès lors qu'il n'est pas possible d'identifier son auteur, un document transmis par télex ne peut constituer le pouvoir spécial visé à l'article 984 du nouveau Code de procédure civile.

## Texte

Sur la recevabilité du pourvoi :

Vu l'article 984 du nouveau Code de procédure civile ;

Attendu qu'en application de ce texte, dans les matières où les parties sont dispensées du ministère d'un avocat au Conseil d'Etat et à la Cour de cassation, le pourvoi peut être formé par un mandataire qui doit être muni d'un pouvoir spécial émanant du demandeur au pourvoi ;

Que le document produit transmis par télex ne permettant pas d'identifier son auteur, le pourvoi doit être déclaré irrecevable ;

PAR CES MOTIFS :

Déclare IRRECEVABLE le pourvoi
