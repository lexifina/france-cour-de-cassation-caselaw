# Cour de Cassation, Chambre criminelle, du 20 novembre 1984, 83-94.150, Publié au bulletin

## Sommaire

CHASSE - Peines - Non-cumul - Contraventions - Article 380 du Code rural - Application (non).

* SOLIDARITE - Infraction au Code rural - Article 390 du Code rural - Infractions connexes - Nécessité.

* PEINES - Non-cumul - Contraventions - Chasse - Article 380 du Code rural - Application (non).

L'article 380 du Code rural, qui prévoit le non-cumul des peines en matière de délits de chasse, ne déroge pas aux principes généraux édictés par l'article 5 du Code pénal, et ne s'applique pas aux contraventions.

CHASSE - Peines - Solidarité - Article 390 du Code rural - Infractions connexes - Nécessité.

La solidarité pour le paiement des amendes, dommages-intérêts et frais, prévue en matière de police de la chasse par l'article 390 du Code rural, ne peut être prononcée qu'à l'encontre de personnes condamnées pour des infractions connexes.
