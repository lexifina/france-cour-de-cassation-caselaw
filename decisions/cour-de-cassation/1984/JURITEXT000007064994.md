# Cour de Cassation, Chambre criminelle, du 28 mars 1984, 84-90.153, Publié au bulletin

## Sommaire

LOIS ET REGLEMENTS - Interprétation - Loi pénale - Interprétation stricte - Article 357-1-1 du Code pénal - Enfant naturel - Application (non).

* ABANDON DE FAMILLE - Abandon de foyer - Article 357-1-1 du Code pénal - Enfant naturel - Application (non).

En raison du principe de l'interprétation stricte des lois pénales, les dispositions de l'article 357-1-1 du Code pénal ne protègent pas les enfants naturels.
