# Cour de Cassation, Chambre civile 2, du 23 mars 1966, Publié au bulletin

## Sommaire

DIVORCE SEPARATION DE CORPS - CASSATION - MOYEN - MOYEN VISANT UN MOTIF SURABONDANT - GRIEF PRIS DE L'APPLICATION DE L'ARTICLE 232 DU CODE CIVIL - DECISION DEJA FONDEE SUR L'ARTICLE 230 DU MEME CODE

LORSQU'UNE DEMANDE EN SEPARATION DE CORPS SE TROUVE JUSTIFIEE SUR LA BASE DE L'ARTICLE 230 DU CODE CIVIL, C'EST PAR DES MOTIFS SURABONDANTS QUE LES JUGES DU FOND L'EXAMINENT SUR LA BASE DE L'ARTICLE 232.    IL S'ENSUIT QU'EST INOPERANT UN MOYEN RELATIF A LA VIOLATION DE CE DERNIER TEXTE.

## Texte

SUR LE MOYEN UNIQUE : ATTENDU QUE, POUR PRONONCER LA SEPARATION DE CORPS AU PROFIT DE DAME X..., LE JUGEMENT, QU'A CONFIRME L'ARRET ATTAQUE, APRES AVOIR ANALYSE LES ELEMENTS DE LA CAUSE ET NOTAMMENT LES TEMOIGNAGES DES ENQUETES, ENONCE QUE L'EPOUSE AVAIT ETE TROMPEE PAR SON MARI QUI AVAIT ENTRETENU DES RELATIONS COUPABLES AVEC UNE JEUNE FILLE;

ATTENDU QU'AYANT AINSI ETABLI QUE LA DEMANDE DE DAME X... ETAIT JUSTIFIEE SUR LA BASE DE L'ARTICLE 230 DU CODE CIVIL, C'EST PAR DES MOTIFS SURABONDANTS QUE LES JUGES DU FOND L'ONT EXAMINEE SUR LA BASE DE L'ARTICLE 232;

D'OU IL SUIT QUE LE MOYEN RELATIF A LA VIOLATION DE CE DERNIER TESTE N'EST PAS FONDE;

PAR CES MOTIFS : REJETTE LE POURVOI FORME CONTRE L'ARRET RENDU LE 30 NOVEMBRE 1964 PAR LA COUR D'APPEL DE PAU;
