# Cour de Cassation, Chambre civile 2, du 27 février 1980, 78-15.062, Publié au bulletin

## Sommaire

CASSATION - Décisions susceptibles - Décision ordonnant une mesure d'instruction - Conditions - Dispositif tranchant une partie du principal.

* CASSATION - Décisions susceptibles - Décision ordonnant une mesure d'instruction - Motifs sans influence.

Est irrecevable le pourvoi formé contre une décision qui se borne à ordonner une expertise.

## Texte

SUR L'IRRECEVABILITE DU POURVOI SOULEVEE PAR LA DEFENSE :

VU L'ARTICLE 150 DU NOUVEAU CODE DE PROCEDURE CIVILE ;

ATTENDU QUE L'ARRET ATTAQUE SE BORNE, "AVANT FAIRE DROIT SUR L'EVENTUELLE RESPONSABILITE DE FERRARI", A ORDONNER UNE EXPERTISE ; QU'AUX TERMES DU TEXTE SUSVISE, UNE TELLE DECISION NE PEUT ETRE FRAPPEE DE POURVOI INDEPENDAMMENT DU JUGEMENT SUR LE FOND ; QUE LE POURVOI EST DONC IRRECEVABLE ;

PAR CES MOTIFS :

DECLARE LE POURVOI IRRECEVABLE.
