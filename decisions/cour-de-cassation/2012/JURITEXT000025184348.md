# Cour de cassation, civile, Chambre civile 1, 18 janvier 2012, 10-26.645, Inédit

## Texte

LA COUR DE CASSATION, PREMIÈRE CHAMBRE CIVILE, a rendu l'arrêt suivant :

Attendu que, par une erreur purement matérielle qu'il convient de réparer, il est mentionné à la page 2 de l'arrêt concerné "Vu l'article 455 du code civil" ;

PAR CES MOTIFS :

Ordonne la rectification de l'arrêt 1155 F-D rendu le 23 novembre 2011 ;

Dit qu'à la page 2 les mots "Vu l'article 455 du code de procédure civile" sont substitués aux mots "Vu l'article 455 du code civil" ;

Dit que le présent arrêt sera transcrit en marge ou à la suite de l'arrêt rectifié ;

Ainsi fait et jugé par la Cour de cassation, première chambre civile, et prononcé par le président en son audience publique du dix-huit janvier deux mille douze.
