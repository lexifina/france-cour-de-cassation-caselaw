# Cour de Cassation, Chambre civile 3, du 21 décembre 1982, Inédit

## Texte

SUR LA RECEVABILITE DU POURVOI : ATTENDU QUE LA DECLARATION DE POURVOI NE FORMULE AUCUN MOYEN REGULIER DE CASSATION ;

QUE CETTE OMISSION N'A PAS ETE REPAREE PAR LA PRODUCTION D'UN MEMOIRE AMPLIATIF DANS LE DELAI PRESCRIT, A PEINE D'IRRECEVABILITE, PAR L'ARTICLE R. 12-5 DU CODE DE L'EXPROPRIATION ;

PAR CES MOTIFS : DECLARE IRRECEVABLE LE POURVOI.
