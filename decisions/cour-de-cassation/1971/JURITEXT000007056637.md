# Cour de Cassation, Chambre criminelle, du 12 mai 1971, 71-91.220, Publié au bulletin

## Sommaire

CRIMES ET DELITS COMMIS PAR DES MAGISTRATS ET CERTAINS FONCTIONNAIRES - Fraude électorale - Infraction commise dans le but de favoriser ou combattre une candidature - Article L 115 du Code électoral - Articles 679 à 688 du Code de procédure pénale - Application (non).

* ELECTIONS - Fraude électorale - Infraction commise dans le but de favoriser ou combattre une candidature - Article L 115 du Code électoral - Articles 679 à 688 du Code de procédure pénale - Application (non).

L'article L 115 du Code électoral exclut toute application des articles 679 à 688 du Code de procédure pénale, en cas de délits commis en vue de favoriser ou de combattre une candidature, quelle que soit la nature de ces délits et quels qu'aient pu être les moyens à l'aide desquels ils se sont réalisés (1).

## Texte

REJET DE LA REQUETE DU PROCUREUR DE LA REPUBLIQUE, PRES LE TRIBUNAL DE GRANDE INSTANCE DE GRENOBLE, TENDANT A LA DESIGNATION DE LA JURIDICTION CHARGEE DE L'INSTRUCTION ET DU JUGEMENT DANS L'AFFAIRE SUIVIE CONTRE X..., DU CHEF DE FRAUDE ELECTORALE LA COUR, VU LADITE REQUETE ;

VU LES DISPOSITIONS DE L'ARTICLE 687 DU CODE DE PROCEDURE PENALE, ENSEMBLE DE L'ARTICLE L 115 DU CODE ELECTORAL ;

ATTENDU QUE LES FAITS DE LA POURSUITE OPERES DANS LE DESSEIN DE NUIRE A LA SINCERITE DE LA CONSULTATION, SONT IMPUTES A X..., MAIRE DE VILLARD-BONNOT, OFFICIER DE POLICE JUDICIAIRE ;

QUE L'ARTICLE L 115 DU CODE ELECTORAL QUI EXCLUT TOUTE APPLICATION DES ARTICLES 679 A 688 DU CODE DE PROCEDURE PENALE, S'ETEND A TOUS LES DELITS COMMIS EN VUE DE FAVORISER OU DE COMBATTRE UNE CANDIDATURE, QUELLE QUE SOIT LA NATURE DE CES DELITS ET QUELS QU'AIENT PU ETRE LES MOYENS A L'AIDE DESQUELS ILS SE SONT REALISES ;

QUE LES FAITS DE L'ESPECE ENTRENT DANS LES PREVISIONS DE CE TEXTE ;

REJETTE LA REQUETE
