# Cour de Cassation, Chambre civile 1, du 18 mars 1971, 70-10.928, Publié au bulletin

## Sommaire

JUGEMENTS ET ARRETS - CONCLUSIONS - OBLIGATION DE JUGER DANS  LEURS LIMITES - FILIATION NATURELLE - PENSION ALIMENTAIRE - DEMANDE  FONDEE SUR L'ARTICLE 340 DU CODE CIVIL - JUGEMENT ET ARRET FONDES  SUR L'ARTICLE 342 DU MEME CODE - ACCORD DES PARTIES.

* ACTION EN JUSTICE - FONDEMENT JURIDIQUE - CHANGEMENT EN CAUSE D 'APPEL - ALIMENTS - DEMANDE FONDEE EN APPEL SUR L'ARTICLE 340 DU CODE  CIVIL - JUGEMENT STATUANT SUR L'ARTICLE 342 DU MEME CODE - DEMANDE  DE CONFIRMATION.

* FILIATION NATURELLE - OBLIGATION ALIMENTAIRE - PENSION  ALIMENTAIRE - CONDAMNATION - FONDEMENT - DEMANDE FONDEE SUR L 'ARTICLE 340 DU CODE CIVIL - JUGEMENT ET ARRET FONDES SUR L'ARTICLE  342 DU MEME CODE - ACCORD DES PARTIES.

* FILIATION ADULTERINE OU INCESTUEUSE - PENSION ALIMENTAIRE - LOI DU  15 JUILLET 1955 - CONDAMNATION - FONDEMENT - JUGEMENT ET ARRET  FONDES SUR L'ARTICLE 342 DU CODE CIVIL - DEMANDE INITIALE FONDEE SUR  L'ARTICLE 340 - ACCORD DES PARTIES.

* PROCEDURE CIVILE - DEMANDE - CAUSE - MODIFICATION - FILIATION  NATURELLE - PENSION ALIMENTAIRE.

STATUANT SUR UNE DEMANDE DE PENSION ALIMENTAIRE FONDEE SUR L 'ARTICLE 340 DU CODE CIVIL, LA COUR D'APPEL PEUT CONFIRMER LE  JUGEMENT DE PREMIERE INSTANCE AYANT ACCORDE CETTE PENSION EN  APPLICATION DE L'ARTICLE 342 DU MEME CODE DES LORS QUE LE CREANCIER  D'ALIMENTS A DEMANDE LA CONFIRMATION DE CETTE DECISION ET QUE LE  DEFENDEUR A CONCLU SUBSIDIAIREMENT SUR L'APPLICATION EVENTUELLE DE  CE TEXTE.

## Texte

SUR LE MOYEN UNIQUE, PRIS EN SA PREMIERE BRANCHE : ATTENDU QU'IL EST FAIT GRIEF A L'ARRET CONFIRMATIF ATTAQUE D'AVOIR CONDAMNE, SUR LE FONDEMENT DE L'ARTICLE 342 DU CODE CIVIL, ETIENNE X... A VERSER UNE PENSION POUR L'ENTRETIEN DES DEUX ENFANTS QUI SERAIENT ISSUS DE SES RELATIONS ADULTERES AVEC LEUR MERE PIERRETTE Y..., ALORS QUE, CETTE DERNIERE AYANT EXCLUSIVEMENT FONDE, A L'ORIGINE, SON ACTION SUR L'ARTICLE 340 DU CODE CIVIL, LES JUGES DU FOND NE POUVAIENT SUBSTITUER A LA DEMANDE PRIMITIVE UNE DEMANDE DONT LA CAUSE ET LE SYSTEME DE PREUVE ETAIENT DIFFERENTS;

MAIS ATTENDU QUE LES JUGES DU PREMIER DEGRE ONT CONDAMNE X... SUR LE FONDEMENT DE L'ARTICLE 342 ALINEA 2 DU CODE CIVIL ET QUE DAME Y... A DEMANDE CONFIRMATION DU JUGEMENT;

QUE DES LORS, LES JUGES D'APPEL ETAIENT SAISIS SUR LA BASE DE CE TEXTE, SUR LEQUEL X... A CONCLU SUBSIDIAIREMENT;

QU'EN CONSEQUENCE, LES JUGES DU FOND ETANT RESTES DANS LES LIMITES DES CONCLUSIONS DES PARTIES LE GRIEF N'EST PAS FONDE;

ET, SUR LA SECONDE BRANCHE : ATTENDU QU'IL EST EGALEMENT FAIT GRIEF A L'ARRET ATTAQUE D'AVOIR LAISSE SANS REPONSE LES CONCLUSIONS D'APPEL DE X..., LESQUELLES SOULIGNAIENT QUE, SI LE DEBAT AVAIT ETE MAINTENU SUR LE TERRAIN DE L'ARTICLE 340 DU CODE CIVIL, LES JUGES DU FOND AURAIENT ETE DANS L'OBLIGATION DE DEBOUTER LA DAME Y... DE SA DEMANDE TENDANT A LA DECLARATION DE PATERNITE NATURELLE DE X...;

MAIS ATTENDU QUE LA COUR D'APPEL N'AVAIT PAS A EXAMINER AU FOND UNE DEMANDE QU'ELLE DECLARAIT IRRECEVABLE;

QU'AINSI LE MOYEN NE SAURAIT ETRE ACCUEILLI;
