# Cour de cassation, civile, Chambre civile 3, 25 janvier 2011, 09-16.896, Inédit

## Texte

LA COUR DE CASSATION, TROISIÈME CHAMBRE CIVILE, a rendu l'arrêt suivant :

Vu l'article 1014 du code de procédure civile ;

Vu les articles 978 et 611-1 du code de procédure civile ;

Attendu que, par application de ce texte, le pourvoi n'est pas recevable ;

DECLARE non admis le pourvoi ;

Condamne les consorts X...-Y...aux dépens ;

Vu l'article 700 du code de procédure civile, rejette la demande des consorts X...-Y...; les condamne, ensemble, à payer aux époux Z... la somme globale de 2 500 euros ;

Ainsi décidé par la Cour de cassation, troisième chambre civile, et prononcé par le président en son audience publique du vingt-cinq janvier deux mille onze.
